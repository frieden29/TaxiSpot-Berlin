# TaxiSpot Berlin v0.1

Prototype Flutter app for taxi drivers in Berlin.

## Included
- Berlin map using OpenStreetMap
- Five initial taxi-demand locations
- TaxiScore 0–100
- Driver location button
- Location detail card
- Open navigation in Google Maps
- "Got a passenger" prototype action

## Run
1. Install Flutter and Android Studio.
2. Create a normal Flutter Android scaffold if needed:
   `flutter create .`
3. Run:
   `flutter pub get`
   `flutter run`

## Important
The current TaxiScore values are demo values, not live demand predictions.
The next phase should replace them with real data sources and a scoring backend.
